## 一、小红书怎么找、怎么吸引「一小撮」对的人

**原则（和你做产品同一逻辑）：** 先 **需求能 match 在一起** 的人，再放大；不要先投「所有学乐器的人」。

**1. 让他们能搜到你**

| 类型 | 关键词示例 |
|------|------------|
| 核心 | 长笛练习、居家练琴、练完怎么知道对错、错音、节奏 |
| 身份 | 长笛学生、长笛家长、长笛老师 |
| 产品 | FluteBuddy、Flute practice（海外家庭/双语） |

**2. 让他们 3 秒看懂你是谁**

- 主号仍是 **张丹瀛 / 法派长笛 / 听见** 人设；FluteBuddy **约 30%** 内容露出（capstone：避免一号双主线）
- 简介一句：**「FluteBuddy：上传谱面+录音，练完就知道错在哪。」**
- 置顶视频：见 **第五节 · 视频 1**

**3. 用什么内容吸引（不是泛娱乐）**

- **场景片：** 练完不敢问老师、家长不敢当裁判、老师希望学生带问题来上课
- **证据片：** 真实 **上传 → 扣分列表 → 谱面小节** 录屏（部署 URL 或清晰 demo）
- **边界片：** 机器判 **基础层**；音乐性/句读 **仍跟老师**（建立信任，避免被专业圈喷）

**4. 用什么动作把人筛出来**

- 评论区固定问：**「你练长笛最烦的是：错音 / 节奏 / 不敢问老师？」**
- 私信三问：年级或水平 / 本周练哪本谱 / 是否愿意上传一次练习 → **只邀 P0 进内测**
- 资料库对齐：精准获客五步法、人群洞察（screen hydrate · file id 见文末）

**5. 发布节奏**

- **每周 2–3 条** 精发（教培起号资料：忌盲目日更）
- 先 **2 周验证** 评论里 P0 占比，再考虑薯条/聚光（Drive 小红书文件夹有投放资料，第二阶段再用）

## 二、合适的人群（FluteBuddy 针对谁）

| 层级 | 是谁 | 为什么 match FluteBuddy |
|------|------|------------------------|
| **P0（首发只打）** | 有 **谱面 PDF**、练完总问「对吗」的 **长笛学生** + **陪伴型家长** | 产品路径就是 PDF+录音 → 反馈；需求与功能 1:1 |
| **P1（第二期）** | **长笛老师 / 工作室**（学生量 10–50） | 希望基础问题在家解决，课上演音乐性；可做 **老师渠道** |
| **P2（引流，不转化主战场）** | 听见 Daily / 古典粉 | 认你专业后再进 waitlist；**不**用纯资讯粉硬推 App |

**不适合首发：** 只想要「长笛种草/买笛子」流量；只要 BG 不要练习的人。

**一小撮画像（一句话）：**  
「家里能拿到 **电子版谱**，孩子或本人 **肯录音**，练完需要 **客观反馈** 而不是空泛夸奖的长笛家庭。」

## 三、分几步做 · 全流程

| 步 | 时间 | 做什么 | 产出 |
|----|------|--------|------|
| **1** | 第 1 天 | 定 P0 一句话 + 搜词表 + 简介/置顶脚本 | 口径文档（本节即 baseline） |
| **2** | 第 2–5 天 | 拍 **5 条视频**（下表）；补 **内测链接**（Owner：部署 URL 或 waitlist） | 可发布素材 |
| **3** | 第 2 周 | 发 3 笔记 + 置顶 + 2 篇「搜词/场景」短文 | 评论/私信数据 |
| **4** | 第 3–4 周 | 30–50 组 **P0 家庭** 内测；收 **练习周报**（buddy 仓 `practice_weekly_summary.py`） | 留存/反馈 |
| **5** | 第 5 周+ | 好则加 **老师渠道**（P1）；好则复制搜词到第二城市/学校圈 | 是否放大 |

**C 步「内测链接」：** capstone 里仍待你填 **正式等候名单 URL**；宣传名已确认为 **FluteBuddy**，不另起陌生品牌名。
